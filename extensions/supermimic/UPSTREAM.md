# Upstream

This extension contains the independent implementation from
`CuboiLeo/SuperMimic-Reproduced` at commit
`ba6105349069bf040f1fdad60873d13138d505a2` (2026-10-26), licensed under the
included MIT license. The upstream project identifies mjlab commit
`8bb2bc9e187797689ec82c78c35019afd2fd0376` as its framework pin.

Local adaptations are limited to using this repository's G1 29-DoF MJCF for
motion conversion and the simulation entity. The upstream algorithm and numerical
training logic are retained.
